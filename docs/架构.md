# 架构

> 常驻规范见 [`../AGENTS.md`](../AGENTS.md)；本文只讲结构与链路，按需阅读。

## 入口加载（`index.js`，单入口）

1. **配置初始化**：`config/config.yaml` 不存在时从 `.example` 复制
2. **别名表**：`buildAliasMap()` 解析 miao-plugin 的 `alias.js`，并只读合并 miao 自定义别名（`config/alias_{gs,sr}.cfg`，`fs.watch` 热更新）
3. **目录确保**：`gallery/`、`gallery/profile/`（旧聚合目录，仅 blocked-character 在用）、`gallery/ProfileImg/`
4. **文件初始化**：`map.json` / `gallery_config.yaml` / `manager_config.yaml` 不存在则创建
5. **图库源登记** `initGallerySources()`（**后台执行、不 await**）：
   - `getLayoutState()` 判三态：`ready`（多源布局）/ `fresh`（miao 配置里没有自有源）/ `legacy`（旧 junction 布局）
   - 非 legacy：`refreshGalleryConfigFile()`（把旧注释刷成当前模板，幂等，含自定义键则跳过）→ `autoRegisterUnregisteredRepos()`（补登记 `gallery/ProfileImg` 下已有但未登记的目录；排除主仓库保留名与旧布局 `default`；含 `.git` 或结构可直读才登记；Git 仓库回填 origin；**每次启动只扫这一次**）
   - 注册 miao：`ready`/`fresh` → `syncProfileImgSrc()`；有变更则日志告警 + 延迟 45s 私聊主人要求重启（24h 节流）；`legacy` → 日志 + 延迟 45s 私聊说明迁移步骤
   - `logSkippedSources()` 打「已配置但未注册」告警；提示统一走 `model/layoutNotice.js`
   - **为什么放后台**：框架 `plugin_load_timeout` 只有 60s，这段要扫目录 / 读写配置 / 读 miao 配置；放在 apps 注册之前会让「启动后最初几秒」的消息无人处理（实测生产 20:03:10 启动、20:03:24 就来消息，那时 apps 还没注册完，`#预览` 被 Atlas 接走）
6. **动态发现 apps**：`readdir` → **先过滤出 `.js`**（`appFiles`，import 与命名遍历同源，避免非 JS 文件导致索引错位）→ `Promise.allSettled(appFiles.map(import))` → 用 `isPluginClass()`（class 的 `prototype` 不可写）挑插件 class，选不出就 `logger.error` 跳过 → 逐条打 `[ProfileImg-Plugin] 载入: xxx`
7. **导出 apps**：key 为文件名（去 `.js`），value 为 class

## 目录职责

| 目录 | 职责 |
|------|------|
| `apps/` | 命令模块，每个文件导出一个 extends `plugin` 的 class |
| `model/` | 数据层：Git、图库源配置（miao `profileImgSrc`）、源结构探测、多源索引、迁移、布局守卫与提示、仓库路由、图库配置、版本查询 |
| `modules/` | 业务层：别名解析、图片压缩、预览渲染（`preview/`）、状态图数据整形（`statusPanel.js`） |
| `components/` | 工具层：配置读取、常量、格式化、通知、版本号、渲染封装、文件名解析 |
| `resources/` | 静态资源：`common/ui.css`（UI 基调）+ `help/` `status/` `visualize/` 出图模板；`resources/gallery/` 为图库运行时目录（git-ignored） |
| `config/` | 运行时配置（git-ignored）+ `.example` 参考 |
| `defSet/` | 锅巴配置模板（`${变量}` 占位符） |
| `data/` | 运行时数据：git 锁文件、仓库版本记录（git-ignored） |
| `test/` | 回归套件（入库，见 AGENTS.md「测试」） |

## 多图库源布局（miao `profileImgSrc`）

```
miao-plugin/resources/profile/                  ← 默认图库（真实目录，源列表首项 'profile'，唯一可写）
└── normal-character/琴/
    ├── 琴_10001_张三_米游社_「琴_1_张三_米游社」.webp   ← default 段位
    └── 琴_10002_甲_乙.webp.bak                        ← .bak 屏蔽（miao 只认 4 种后缀，不可见）

ProfileImg/resources/gallery/ProfileImg/
├── miao-plugin-ProfileImg[-N]/                 ← 主仓库（独立只读源，自带 .git）
└── <第三方图库>/                                ← 第三方只读源（分层 / 平铺 / 一层分组）

miao-plugin/config/profile.js                   ← profileImgSrc = ['profile', 主仓库绝对路径, 第三方绝对路径…]
```

- 上游 miao 2.5.20+ 支持有序数组多源：按 `{源}/normal-character/{角色}/`、`{源}/super-character/{角色}/` 或平铺 `{源}/{角色}/` 读取，**同层多源合并后随机取图**
- **不再使用 junction 与物理复制**：默认图库是真实目录，各仓库直接注册为源（跨平台一致）
- `.bak` 不可见依赖「miao 只认 webp/png/jpg/jpeg」这一契约

## 序号段位（`n` 的编码来源）

| 来源 | 段位 | 说明 |
|------|------|------|
| 主图库（各主仓库源） | 1 ~ 9999 | `components/panelUtils.js` 的 `resolveNRange(n)` 判定 |
| 默认图库（`resources/profile`） | 10001 ~ 99999 | 写盘取号用 `getNextSeqInRange(dir, role, start, end)` 取段位内最小空缺 |
| 第三方图库源 | 不参与 | 第三方原生命名，仅展示，需在源仓库管理 |

列表 / 删除 / 屏蔽 / 启用共用 `n`；默认图库文件名规范见 `docs/图库源与配置.md`。

## 数据流

**上传 / 替换 / 预览**
```
QQ消息 → rule 正则 → isManager() 权限（成员需允许 default）→ guardLayout()
  → resolveRoleName() → 新角色 autoAssignRepo()（map.json 记归属）
  → 写默认图库（default 段位 10001+）；主人把 gallery.defaultDir 配成主仓库 → 直写 main 段位
  → miao 通过 profileImgSrc 直接读各源，不再复制

#替换<角色>面板图N + 图片 → 按段位定位 → 取源级锁 → 字节按目标扩展名压缩/转格式 → 同名覆盖（不改名）

#预览<角色>面板图N → 序号定位立绘（不存在则自行提示）→ 构造虚拟面板 → 组装 miao 面板模板数据
  → Common.render('character/profile-detail', …) → 直接 e.reply(图片段)
```

**列表 / 可视化**
```
#xx面板图列表 → resolveRoleName → listRoleImages（跨源汇总）→ 合并转发（上限 20 张）
#xx面板图可视化 → 同上跨源读取 → 按 displayN 排序 → 每页 20 张（4×5）逐页截图发送
```

**初始化 / 迁移 / 下载更新 / 屏蔽启用** → 见 `docs/维护与迁移.md`。

## 框架全局变量

| 变量 | 说明 |
|------|------|
| `Bot` | Yunzai 实例：`Bot.uin` / `Bot.pickGroup()` / `Bot.sendMasterMsg()` / `Bot.pickFriend(qq).sendMsg()` |
| `logger` | `info` / `warn` / `error` / `mark`（框架等级 info，`debug` 等于不输出） |
| `segment` | oicq 消息段构造器：`segment.image()` / `segment.at()`（`puppeteer.screenshot` 的返回值已被包成图片段） |

| `cfg` | 框架配置 Proxy：`cfg.getGroup(bot_id, group_id)` |
| `redis` | 本插件不直接使用 |
