# 图库源与配置

> 常驻规范见 [`../AGENTS.md`](../AGENTS.md)；本文讲配置三层、源结构探测、登记流程与命名规则。

## 配置三层 + 锅巴

| 文件 | 用途 | Git |
|------|------|-----|
| `defSet/config.yaml` | 主配置模板（`${变量}` 占位符 + 注释） | ✓ |
| `defSet/gallery_config.yaml` | 图库配置模板（锅巴保存时替换 `${gallery_thirdParty}`） | ✓ |
| `defSet/manager_config.yaml` | 成员权限模板（替换 `${managers_list}`） | ✓ |
| `config/config.yaml` | 主配置运行时（统一自动更新 / 仓库元数据 / 屏蔽 / 第三方 / 上传压缩） | ✗ |
| `config/gallery_config.yaml` | 图库配置运行时 | ✗ |
| `config/manager_config.yaml` | 成员权限运行时 | ✗ |
| `config/*.yaml.example` | 参考默认值（`getPluginConfig` 兜底来源） | ✓ |

- 锅巴 field 用**点分隔路径**（`gallery.autoUpdate.enabled`），模板变量用**下划线**（`gallery_autoUpdate_enabled`）
- `getPluginConfig` 兜底：`config.yaml` 不存在时从 `.example` 复制；**禁止**解析 `defSet/config.yaml` 过滤 `${变量}` 当兜底（占位符替换成空串会生成非法 YAML）
- 写配置必须保注释：`writeGalleryConfig()` 按 `defSet/gallery_config.yaml` 模板渲染，锅巴保存与插件内写入共用
- 存量注释刷新：启动 / 初始化时 `refreshGalleryConfigFile()` 重渲染并比对（不同才写回；出现 `thirdParty` 以外的键则跳过；legacy 状态不刷新）

关键配置项：`gallery.autoUpdate`（统一 cron + 总开关，默认 `0 30 5 * * *`）、`gallery.repos[]`（主仓库 URL / 参与自动更新）、`gallery.blocked`（enabled + URL）、`gallery.thirdPartyUpdate.enabled`、`gallery.defaultDir`（主人手动上传目录）、`upload`（压缩）。

## 能力门槛

- `supportsMultiSrc()` 探测 miao 的 `profile_default.js` 是否含 `profileImgSrc`：**不支持（miao < 2.5.20）时 `#迁移图库` / `#图库初始化` 直接拒绝**，不做降级兼容
- `#预览` 另需 miao 的面板模板与内部模块可用：`modules/preview/miao.js` 惰性探测（相对路径 import + 缓存），拿不到时命令侧给出提示而不是报错

## 第三方图库源结构（`model/srcProbe.js` 自动探测）

| 结构 | 判据 | 注册 |
|------|------|------|
| `tier` 分层 | 根含 `normal-character/{角色}/` 或 `super-character/{角色}/` | 自身一项 |
| `flat` 平铺 | 平铺 `{角色}/`（仅普通立绘）；根目录含**有图的非角色目录**（docs 等）判为不安全 | 自身一项 |
| `group` 一层分组 | `{分组}/{角色}/`（如 `gs-character` / `sr-character`，MBT 形态）；**不依赖命名**，根下任何本身可直读的子目录各算一个子图库，工具 / 隐藏目录跳过；平铺子目录还须含至少一个角色**目录** | 展开为每个子目录一项 |
| `unsupported` | 不符上述 | 不注册，命令 / 状态提示整理目录 |

- **`resolveSourceDirs(probe, { allowGroup })` 是唯一展开入口**：`buildSrcList()`（注册给 miao）与 `galleryIndex.getSources()`（插件读取）共用；**只有第三方图库传 `allowGroup: true`**，主仓库 / 默认图库命中分组会记入 `skipped`
- 分组子源标签一律用**目录原始名**：`图库名·gs-character`（不做游戏名翻译）；`getSources()` 还给它们补 `parent` / `groupName`（状态图据此归层级）

## 登记流程（单向固定）

```
添加图库（QQ 命令 / 锅巴 / 配置文件）→ 写 gallery_config.yaml（唯一凭证）
  → syncProfileImgSrc() 从配置注册 miao → 提示重启（重启提示一律走 components/notify.js 的 restartHint()）
```

- **只有配置里的条目会被读取 / 注册**，不以目录扫描为准；扫描结果**永不**直接作为 miao 源
- `gallery/ProfileImg` 下已有但未登记的目录由 `listUnregisteredRepos()` 发现（排除主仓库保留名与旧布局 `default`）→ `autoRegisterUnregisteredRepos()` **先补登记进配置**（Git 仓库回填 origin）
- **legacy 布局下不做补登记**（此时 `ProfileImg/default` 是旧 default 图库，交给 `#迁移图库`）
- `#图库状态` 与启动日志只提示仍未登记的目录

## 路径约定

- `thirdParty[].dir` 一律写**绝对路径**（含其他盘 / 网络盘 UNC，正斜杠）；读取兼容旧相对名（相对 `gallery/ProfileImg`）
- `#下载第三方图库 <URL> [目标目录]` 可指定落点；**目标目录非 Git 且非空时拒绝下载**（`installRepoAsync` 同理防覆盖本地图库，提示改为在锅巴 / 配置里登记该绝对路径）
- `#删除第三方图库` 仅删「Git 仓库目录」，保护磁盘根 / 图库根 / 默认图库 / 主图库
- 网络盘需先 `git config --global --add safe.directory <路径>`（否则 git 以 dubious ownership 拒绝）；路径变更后需重启

## 成员权限（`config/manager_config.yaml`）

```yaml
managers:
  - qq: 123456789
    repos: "main,default,米游社"   # 逗号分隔；留空 = 仅允许 default
```

- 图库 key：`main`（主图库一体）/ `default`（默认图库）/ 第三方图库名
- 判定：`isManager(e)`（主人恒通过）→ 非主人再 `canAccessGallery(user_id, gkey)` 按图库边界校验；边界由 `resolveGalleryKey(filename, roleName, n)` 按段位 + 文件名前缀反查
- **成员规则不带 `permission:'master'`**（rule 层会拦掉，函数内检查到不了）；四类成员指令 = 添加 / 删除 / 屏蔽 / 启用（重命名保持 master）
- 成员上传恒写默认图库（需允许 `default`），与 `gallery.defaultDir` 解耦；主人可把它配成主仓库目录直写 main 段位

## 文件命名格式

| 场景 | 格式 |
|------|------|
| 主图库（含版权） | `<角色名>_<序号>_<原作者>_<来源>[_<备注>].扩展名`，序号 1~9999 |
| 主图库（无版权） | `<角色名>_<序号>.扩展名` |
| 默认图库（default 段位） | `<角色名>_<序号>_<原作者>_<来源>[_<备注>]_「<原文件名>」.扩展名`，序号 10001~99999 |
| 第三方图库源 | 第三方原生命名，不参与段位与 `#面板图N` |
| 屏蔽（默认图库） | `.bak` 后缀（miao 不可见） |
| 屏蔽（主图库） | 移入 `blocked-character`，按空位重排 `n` |

- 各部分禁止空格，用 `_` 分隔；「原名」备注段由迁移时 `buildDefaultName()` 生成，便于追溯
- `#替换xx面板图N` **不改名**：只覆盖该序号文件的字节，文件名（序号 / 版权 / 备注 / 扩展名）一律不动；第三方源不参与序号，直接拒绝
- **写入的字节必须匹配扩展名**：上传 / 替换统一走 `_toTargetFormat()`（先按 `upload` 压缩 → `detectFormat()` 校验 → 不符则 `convertToFormat()` 重编码）

## map.json

```json
{ "version": 1, "mapping": { "琴": 0, "胡桃": 1 } }
```

角色 → 主仓库编号（唯一路由；同一角色 normal+super 在同一主仓库）；新角色由 `autoAssignRepo` 分到角色数最少的仓库。多源布局下它已不是唯一路由，后续可降级（见待办）。

## 存储路径

```
miao-plugin/resources/profile/{normal,super}-character/{角色}/   ← 默认图库（真实目录，唯一可写）
ProfileImg/resources/gallery/
├── map.json                       ← 角色 → 主仓库编号
├── profile/blocked-character/     ← 屏蔽图库（自带 .git）
├── backup/migrate-<时间>/         ← 迁移前配置备份
└── ProfileImg/<主仓库|第三方图库>/  ← 独立只读源
```
