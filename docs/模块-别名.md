# 模块：角色别名（`modules/alias.js`）

> 常驻规范见 [`../AGENTS.md`](../AGENTS.md)；改别名相关代码前读本文。
> 来源：Atlas-Plugin 交付的对外门面 `Atlas-Plugin/modules/aliasApi.js`（契约版本 `ALIAS_API_VERSION`）。接入只依赖该门面，Atlas 侧不代改本插件；**不要引用 Atlas 的文档路径**（其交接文档会改为通用规范，路径可能失效）。

## 来源优先级

| 顺序 | 来源 | 说明 |
|---|---|---|
| 1 | **Atlas 门面** `Atlas-Plugin/modules/aliasApi.js` | 契约版本 `ALIAS_API_VERSION = 1`；表 3000+ 键，含武器 / 圣遗物 / ZZZ、多值、六种间隔号归一。**永不抛错**，异常返回空结构 |
| 2 | 本地兜底（本文件实现） | 解析 miao `meta-{gs,sr}/character/alias.js` + `alias_{gs,sr}.cfg`，约 1900 条、仅角色名。**已冻结：不删、不改语义、不再维护** |

- Atlas 可用判定：动态 import 成功且 `getAliasStatus().keys > 0`（装了 Atlas 但别名表为空 → 仍走兜底，否则所有别名静默失效）
- 启动日志二选一（**没有这行就无法判断某台机器走的是哪条路**）：
  - `[ProfileImg-Plugin] 别名来源：Atlas（v<version> / <keys> 键）`
  - `[ProfileImg-Plugin] 别名来源：本地兜底（Atlas 不可用）` / `（Atlas 别名表为空）`

## 解析顺序（`resolveRoleName(name, game)`）

```
① Atlas：resolveAlias(name, gameId) → candidates（对侧候选名，已按游戏过滤）
   → 逐个用「图库角色目录存在」（roleDirExists）裁决，第一个存在的胜出 → normalizeRoleName
② 未命中 / 不可用 → 本地四级回退：别名表（也要求目标目录存在）→ 目录精确 → 大小写不敏感 → 模糊唯一命中
③ 都不中 → 原样返回（并 warn），最后统一 normalizeRoleName（Pro → 基础角色）
```

- 门面返回的是**对侧候选名而非标准名**（表双向、不记方向），最终角色名由**本插件的图库目录**裁决 ✅ 目录语义留在我们这边
- `game` 传参：我们的 `gs` / `sr` → Atlas `gi` / `hsr`；不传 = 不按游戏过滤
  - `apps/previewProfileImg.js` 传 `cmd.game`（`#`=原神 / `*`=星铁 / `#星铁`）——交接里的硬要求
  - 其余角色类命令传 `e.game`（`*` / `#星铁` 前缀时框架置 `sr`，普通 `#` 为 undefined）

## watcher 二选一

- **Atlas 可用时不调用 `watchCustomAliasFiles()`**：Atlas 首次 `loadAliasMap()` 会自己挂 watcher（目录树 + cfg）
- 只有兜底路径才启用本地那套（`fs.watch` 目录 + `fs.watchFile` 兜底）；同时挂会让同一批 cfg 被监听两次、每次保存重建两次

## 两条路径不等价（降级的固有代价）

| 关注点 | 本地兜底 | Atlas 门面 | 影响 |
|---|---|---|---|
| 表规模 | ~1900 条（仅 gs/sr 角色名） | 3000+ 键（含武器 / 圣遗物 / ZZZ） | 命中面变大；非角色名会被目录闸门挡掉，行为不变 |
| 间隔号 | 键只 `toLowerCase()`，`•` / `·` 不互通 | 六种间隔号统一去掉 | **变宽**：`知更鸟·晴歌` 与 `知更鸟•晴歌` 等价；兜底只能靠短别名（`晴歌`）命中 |
| 多值 | 单值（后写覆盖） | 同一键可挂多个候选（含跨游戏） | 取候选逐个过目录闸门；我们始终**传 game**，避免跨游戏误选 |
| 覆盖语义 | 后写覆盖预设 | 四层严格覆盖（外部预设 < miao 自定义 < Atlas 预设 < Atlas 自定义） | Atlas 预设层（`resources/alias/**`）会一并生效 |
| 热更新 | 本地 2 套 watcher | Atlas 自己的 watcher | 二选一，见上 |

## 接入注意（门面契约）

- **必须动态 import + try/catch**：静态 import 在 Atlas 未装 / 被禁用时会让本插件**整个加载失败**，兜底就没机会
- 门面只读、不提供写入与重建；返回的 Map 是 Atlas 的缓存实例，消费者视为 immutable
- 需要"派生缓存"时用 `getAliasVersion()` 比对失效（重建后版本必然 +1）
- `expandKeyword(kw, gameId)` 可用于多候选检索（本插件当前未用，单值语义走候选逐个裁决）
- 排障：`getAliasSource()`（`{kind, version, keys}`）、Atlas 侧 `getAliasStatus()`
