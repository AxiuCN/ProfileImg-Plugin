# 模块：面板图预览（`#预览<角色>面板图N`）

> 常驻规范见 [`../AGENTS.md`](../AGENTS.md)；改预览相关代码前读本文。

## 做什么

`#预览xx面板图N` **不写 miao 数据、也不改写消息交给 miao**，而是「构造虚拟面板 → 把立绘换成该序号的图 → 用 miao 自己的面板模板渲染」：

```
parsePreviewCommand(e.msg) → resolveRoleName → findImageByN(role,'normal',n)（无序号则自行提示）
  → buildVirtualProfile（虚拟 Avatar）→ buildPanelRenderData（组装 miao 面板数据）
  → Common.render('character/profile-detail', …, { e, scale: 1.6, retType: 'base64' }) → e.reply(图片段)
```

不再依赖 miao 的任何 fork 私有能力（`面板图N` / `补` / rule 放宽），上游 miao 同样可用；**序号不存在时本插件自行提示**（miao 取不到序号会随机回退，会张冠李戴）。

## 命令解析（`modules/preview/index.js` 的 `PREVIEW_CMD_RE`）

`#预览xx面板图N` / `*预览xx面板图N` / `#星铁预览…` / `#原神预览…`；rule 与解析共用同一个正则。框架会把 `*` 归一成 `#星铁`，所以 `星铁` 与 `原神` 之外的写法不会出现（别把星铁系各种写法抄进正则）。

## 游戏判定

- **已知角色：游戏以 miao 数据为准**（`Character.get(name).isSr`）——用前缀猜会让星铁角色按原神解析（等级 / 属性表越界）
- **miao 尚未收录的角色**：按前缀定游戏（`#`=原神 / `*`=星铁）并借**占位骨架**（`PLACEHOLDER_CHAR`：原神 胡桃 / 星铁 三月七）

## 虚拟数据（`modules/preview/virtual.js`）

- 伪造 UID `100000009`（游戏内测并不流出的 uid）+ 等级 90（原神）/ 80（星铁）+ 伪造天赋 + 默认武器（原神西风系 / 星铁按命途）+ **一套跨角色复用的伪造圣遗物**
- **不走 miao 的 Player**：`ProfileChange.getProfile` 会给伪造 uid 落一个空存档文件（`data/PlayerData/{gs,sr}/100000009.json`）→ 自己 `new miao.Avatar(fakeDs)`，属性 / 评分 / 伤害都由 miao 模型算
- **等级上限**：星铁 >80 会触发 `Attr.calcPromote` 越界（`Cannot read properties of undefined (reading 'attrs')`），武器等级也要 ≤80（`maxLv` 是 90）
- 伤害算不出就隐藏伤害区（`dmgCalc: {}` 安全）

## 伪造圣遗物（`modules/preview/fakeArtis.js`）

- 必须用**真实 id**：`mainId` / `attrIds` 取自 miao 元数据（原神 `Meta.getMeta('gs','arti').attrIdMap`；魔女 5 件）
- 星铁还要 `Artifact.get(id)` 认得出：过客 `61011-61014` + 位面饰品 `63015/63016`（**位面饰品是独立套装**，5/6 号位取自球/绳套装），`mainId` 取 `metaData.mainIdx[1..6]`，`attrIds` 是 `"id,count,step"` 字符串
- 凭空写字段会被 miao 静默跳过（面板上少词条）

## 渲染数据与 miao 契约（`modules/preview/renderData.js`）

- **import miao 内部模块只能用相对路径**（`../../../miao-plugin/models/index.js`）：`#miao` 别名只对 miao 自身生效
- 模板硬要求字段齐备：`data` / `data.talent` / `attr` / `artisDetail` / `artisKeyTitle` / `dmgCalc`，缺一个就抛错；`data.dataSource='虚拟预览'`，面板顶部有「虚拟面板，非实际账号数据」标注
- **立绘路径按 miao 规则转换**（`modules/preview/splash.js` 的 `toTemplatePath`）：同盘 → 相对 miao `resources` 的路径（basename 要 URL 编码），跨盘 → `file://` URL；Windows 绝对路径会被模板 `_imgUrl` 拼坏
- 渲染结果**直接 `e.reply`**（见 [`UI-出图.md`](UI-出图.md)：框架已把截图包成图片段）

## 占位骨架

- 仅未收录角色：只把 `data.name` / `data.abbr` / `data.imgs.face` 与立绘换成目标角色，其余（技能图标、数值）用骨架角色的
- 顶部横幅标注「该角色（X）尚未收录进 miao-plugin：图标与数值为占位数据，仅用于预览面板图」
- 已知角色的游戏一律以 miao 数据为准（前缀不改变游戏）；序号必须先命中图库里的图，否则不渲染
